cuts - the films (optional)
===========================

Copy the 63 films from your CD of "Z" here (about 330 MB):

  Copy CD0:CUTS/#? Work:Games/ZOD/cuts/

Without them the game runs the same, only without cutscenes. See
doc/Install.txt.

-----------------------------------------------------------------------

cuts - filmy (opcjonalnie)

Skopiuj tu 63 filmy z plyty "Z" (ok. 330 MB):
Copy CD0:CUTS/#? Work:Games/ZOD/cuts/
Bez nich gra dziala tak samo, tylko bez przerywnikow.

-----------------------------------------------------------------------

cuts - die Filme (wahlweise)

Kopieren Sie die 63 Filme von Ihrer CD von "Z" hierher (etwa 330 MB):
Copy CD0:CUTS/#? Work:Games/ZOD/cuts/
Ohne sie läuft das Spiel genauso, nur ohne Zwischensequenzen.
